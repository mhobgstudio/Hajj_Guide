# Hajj Companion — Interactive Pilgrimage Guide

A complete interactive guide to the Hajj pilgrimage — from intention to farewell Tawaf.

## Features

- 🕋 **6 Content Tabs** — Overview, Ihram Rules, Types, Steps, Duas, Checklist, FAQ
- 🔴 **Ihram Rules** — Prohibited and recommended acts with detailed explanations
- 📋 **Types of Hajj** — Tamattu', Qiran, Ifrad comparison table
- 🚶 **9-Step Ritual Guide** — Horizontal scrollable cards with detailed instructions
- 🤲 **Dua Collection** — Arabic text, transliteration, and translation
- ✅ **Interactive Checklist** — Track preparation items with progress bar
- ⏰ **Hajj Countdown** — Dynamic timer to next Hajj season
- 🌙 **Dark/Light Theme** — Toggle with localStorage persistence
- 📱 **PWA Support** — Works offline after first visit

## Quick Start

```bash
cd Hajj_Guide
python3 -m http.server 8080
# Open http://localhost:8080
```

## Tech

Single-file HTML/CSS/JS application. No build step, no dependencies.
